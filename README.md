# บันทึกบิล — คู่มือติดตั้ง

## ไฟล์
- `index.html` — ตัวแอปทั้งหมด
- `sw.js`, `manifest.webmanifest`, ไอคอน `.png` — ทำให้ติดตั้งบนหน้าจอโฮมและเปิดได้แม้ออฟไลน์
- `Code.gs` — โค้ด Google Apps Script สำหรับรับข้อมูลเข้า Google Sheet (มีปุ่มคัดลอกในแอปด้วย)

## 1) เอาแอปขึ้นเว็บ (ต้องเป็น HTTPS) — เลือกทางใดทางหนึ่ง
**GitHub Pages (ฟรี ถาวร)**
1. สร้าง repository ใหม่ใน github.com → อัปโหลดไฟล์ทั้งหมด (ยกเว้น README และ Code.gs ก็ได้)
2. Settings → Pages → Branch: `main` / root → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อคุณ>.github.io/<repo>/`

**Netlify Drop**: ลากโฟลเดอร์ไปที่ app.netlify.com/drop แล้วสมัคร/Claim site เพื่อให้ลิงก์อยู่ถาวร

> ห้ามเปลี่ยนลิงก์ภายหลัง: ข้อมูลผูกกับโดเมน ถ้าย้ายลิงก์ ให้ "สำรอง JSON" จากลิงก์เก่าแล้ว "กู้คืน" ในลิงก์ใหม่

## 2) ติดตั้งบน iPhone
1. เปิดลิงก์ด้วย **Safari**
2. ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าจอโฮมเสมอ — iOS จะไม่ล้างข้อมูลของแอปที่ติดตั้งแบบนี้ (ถ้าเปิดผ่าน Safari เฉยๆ แล้วไม่ใช้นานเกิน 7 วัน iOS อาจล้างข้อมูล)

## 3) เชื่อม Google Sheets
1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script
2. วางโค้ดจาก `Code.gs` → แก้ `const SECRET = 'CHANGE-ME';` เป็นรหัสลับของคุณ → บันทึก
3. Deploy → New deployment → Web app · Execute as: **Me** · Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์
4. ในแอป: ตั้งค่า → ซิงก์ไป Google Sheets → วาง URL (ลงท้าย /exec) + รหัสลับ → **บันทึกและทดสอบ**

แก้โค้ด Apps Script ภายหลัง ต้อง Deploy → Manage deployments → Edit → Version: New version (URL เดิม)

## การอ่านสลิป
- **อ่านในเครื่อง (ค่าเริ่มต้น)**: ฟรี ใช้ Tesseract ภาษาไทย+อังกฤษ ครั้งแรกต้องต่อเน็ตเพื่อดาวน์โหลดข้อมูลภาษา ความแม่นปานกลาง โดยเฉพาะชื่อร้านภาษาไทย
- **Gemini API**: แม่นกว่ามาก ขอ API key ฟรีที่ aistudio.google.com แล้วใส่ในตั้งค่า (รูปสลิปจะถูกส่งไป Google)
- อ่านไม่สำเร็จ/ออฟไลน์ → แอปแจ้งเตือนและให้กรอกเอง รูปยังแนบไว้ตามปกติ
